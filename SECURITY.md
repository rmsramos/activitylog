# Security Policy

## Supported Versions

| Branch | Filament | Supported |
| --- | --- | --- |
| `1.x` | v3 | ✅ |
| `2.x` | v4 | ✅ |
| `3.x` | v5 | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability, please open a [GitHub Security Advisory](https://github.com/rmsramos/activitylog/security/advisories/new) instead of a public issue. We'll acknowledge the report and work with you on a fix and disclosure timeline.
